# Mural

Um mural de notícias bem pequeno, em JavaScript puro. É o projeto de treino do curso:
a gente usa ele pra conhecer o Claude Code antes de construir o portal de verdade.

```
npm start    # abre o mural em http://localhost:5500
npm test     # roda os testes
```

## Hooks

O `.claude/hooks/registrar.mjs` anota no `.claude/hooks.log` cada arquivo que o Claude edita.

## Sobre

Repositório de treino do curso Claude Code na Prática.

## Como contribuir

Rode `npm test` antes de cada commit.
